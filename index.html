온나라 Note 개인정보처리방침

시행일: 2026년 10월 17일

요약 — 온나라 Note는 사용자 PC의 브라우저 안에서만 동작합니다. 개발자를 포함한 누구에게도 정보를 보내지 않으며, 회원가입·로그인·광고·사용 통계 수집이 없습니다.

1. 이 방침이 적용되는 대상

이 방침은 Microsoft Edge 브라우저 확장 프로그램 온나라 Note(이하 "확장")에 적용됩니다. 확장은 공공기관 온나라 문서시스템을 쓰는 사용자의 업무를 돕는 보조 도구입니다. 개인이 만들었으며, 온나라 시스템을 운영하는 기관과는 관계가 없습니다.

2. 확장이 읽는 정보

확장은 사용자가 직접 입력한 온나라 주소의 화면에서만 동작합니다. 그 화면에서 사용자가 이미 볼 수 있는 정보만, 사용자의 로그인 상태 그대로 읽습니다. 다른 웹사이트의 정보는 읽지 않습니다.

읽는 정보쓰는 곳
로그인한 사용자의 이름, 부서, 화면에 가려져 표시되는 아이디같은 PC를 여러 사람이 쓸 때 기록을 사람별로 나누기 위해
문서 목록(제목, 문서번호, 부서, 날짜, 첨부 정보)메모·기한 표시, 문서 찾기, 첨부 받기
사용자가 연 문서의 본문공문 요약(요청 사항, 기한, 문의처 전화번호·이메일)을 만들기 위해
대기 문서 수아이콘 배지와 새 문서 알림

3. 저장하는 정보와 저장 위치

아래 정보는 모두 사용자 PC의 브라우저 저장소(확장 전용 저장 공간)에만 저장됩니다. 인터넷의 다른 서버에는 저장하지 않습니다.

저장 정보내용
사용자가 만든 기록메모, 공문 요약과 기한, 수합(부서별 회신 현황), 사용자가 고친 수신자 그룹표
현재 사용자이름, 부서, 가려진 아이디
작업 편의 정보최근에 본 문서의 제목·문서번호·첨부 정보(개수 상한을 두고 오래된 것부터 지움), 대기 문서 수, 화면 위치 같은 상태 값
설정온나라 주소, 알림 주기, 화면 설정 등

사용자가 백업 내보내기, 본문·첨부 받기, 요약 복사를 누르면 해당 내용이 사용자 PC의 다운로드 폴더나 클립보드로 저장됩니다. 이후의 관리는 사용자에게 있습니다. 업무 자료이므로 소속 기관의 규정에 따라 다루어 주세요.

4. 외부 전송과 제3자 제공

  • 확장은 개발자나 제3자에게 어떤 정보도 보내지 않습니다.
  • 확장이 하는 네트워크 통신은 사용자가 입력한 온나라 서버와의 통신뿐입니다(목록 조회, 대기 문서 수 확인, 문서·첨부 받기).
  • 광고, 사용 통계·분석 도구, 외부 코드 불러오기를 쓰지 않습니다.
  • 공문 요약은 AI 서비스가 아니라 PC 안에서 규칙에 따라 만듭니다.

5. 보관 기간과 삭제 방법

저장한 정보는 사용자가 지울 때까지 보관됩니다. 다음 방법으로 언제든 지울 수 있습니다.

  • 내 기록 모두 지우기: 사이드 패널 → 설정 → 데이터. 로그인한 사람의 기록만 지웁니다.
  • 전체 삭제: 기한·메모·수합 화면에서 항목별로 지웁니다.
  • 확장 제거: 확장을 제거하면 확장이 저장한 모든 정보가 브라우저에서 함께 지워집니다.

7. 안전에 관한 안내

  • 저장된 정보는 암호화되지 않은 상태로 브라우저 저장소에 있습니다. PC 자체의 잠금과 계정 관리로 보호해 주세요.
  • 사람별 기록 분리는 화면에서 서로의 기록이 보이지 않게 하는 기능이며, 같은 PC의 다른 사용자가 저장 파일에 직접 접근하는 것까지 막는 보안 기능은 아닙니다.
  • 확장은 온나라에 글을 쓰거나 고치지 않습니다.

Summary in English

Onnara Note runs entirely inside the user's browser. It works only on the On-nara server address the user enters and grants access to, and reads only what the signed-in user can already see there (user name, department, masked user ID, document lists, and the content of documents the user opens). Memos, document summaries, deadlines, collection status and settings are stored locally in the extension's browser storage. No data is sent to the developer or any third party; the only network traffic is with the user's own On-nara server. There are no accounts, ads, analytics or remote code. Users can delete their data at any time via Settings → Data → "Delete all my records", or by removing the extension. Contact: sonye@korea.kr.
